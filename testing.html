Before you cover it

Inspection occurs before piping is concealed.

NFPA 99-2024 §5.1.12.3.1.1 places system inspection before piping distribution systems are hidden in walls, ceilings, chases, trenches, underground, or otherwise concealed.

Inspection checkpoint

What the installer should have ready

  • Installer testing completed and documented as applicable.
  • Initial pressure test ready for required witnessing.
  • Concealed piping still visible for inspection.
  • Required labels and valve tags in place for concealed components.
  • Project records available for the verifier handoff.

NFPA 99-2024: §5.1.12.3.2.1 addresses witnessing of the installing contractor's initial pressure tests and documentation for the verifier.
