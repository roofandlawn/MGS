# Med Gas (MGS)

Starter web app for organizing medical-gas field work.

## Current prototype

- Mobile-friendly dashboard
- Project list
- Medical-gas system overview
- Inspection / verification checklist
- Alarm and outlet tracking placeholders
- Local browser storage for prototype data

## Run it

Open `index.html` in a browser, or serve the repository with any static web server.
